These exercises are based directly on the supplied `micrograd.ipynb`.

2. `02_value_forward_operations.ipynb`

4. `04_backprop_and_graphs.ipynb`

7. `07_training_and_pytorch.ipynb`
8. `08_full_rebuild_challenge.ipynb`

## Repetition method

- Pass 1: use notes and focus on correctness.
- Pass 2: restart the kernel and solve without looking at the source notebook.
- Pass 3: explain every derivative and tensor/data flow aloud before running tests.
- A test failure is feedback, not the final answer. Read the test name and inspect the smallest relevant function.

The `reference_solutions.ipynb` notebook is intentionally separate. Use it only after a serious attempt.
